# CodeAlpha E-commerce Store

## Description
A Django-based E-commerce Store developed as part of the CodeAlpha Python Programming Internship.

## Features
- User-friendly homepage
- Product listing
- Product detail page
- Shopping cart
- Checkout page
- Django Admin Panel

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite3

## How to Run
1. Clone the repository.
2. Install Django:
   pip install django
3. Run migrations:
   python manage.py migrate
4. Start the server:
   python manage.py runserver
5. Open:
   http://127.0.0.1:8000/
